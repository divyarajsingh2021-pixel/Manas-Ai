**Breaking the Language Barrier in Tech Education for Rural Rajasthan**

## 🌟 Overview
**Manas AI** is a voice-first IT Mentor designed specifically for the students of rural Rajasthan. While the world is racing ahead with AI, many students in our villages are left behind because they don't speak technical English. 

Manas AI acts as a bridge, explaining complex computer science concepts (like RAM, Motherboards, and Coding) in the native **Mewari dialect**. 

## 🚀 Key Features
- **Hyper-Local Mentorship:** Understands and responds in the local Mewari dialect.
- **Voice-Activated Learning:** Hands-free interaction using real-time Speech-to-Text.
- **Zero-Barrier Access:** A lightweight web application that runs on any mobile browser—no heavy downloads required.
- **Interactive IT Curriculum:** Teaches fundamental IT concepts through natural conversation.

## 🛠️ Built With (Google Technologies)
This project leverages Google’s powerful ecosystem to provide a seamless user experience:
- **Google Web Speech API:** Powers the real-time speech recognition (STT) and the voice synthesis (TTS) that brings the "Mewari Guru" to life.
- **Google Chrome Engine (V8):** Optimized for high-speed JavaScript execution for a low-latency AI experience.
- **Google Fonts (Outfit):** Provides a modern, clean, and professional User Interface.
- **Gemini Architecture:** Designed for future integration with Gemini LLM for deeper linguistic understanding.
